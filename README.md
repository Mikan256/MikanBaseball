# みかん野球 (MikanBaseball)

ブラウザで遊べる野球ゲーム。ビルド不要の素の JavaScript（ES Modules）で動く。

自分で選手の能力値と打線を組み、疑似3Dのフィールドで 9 回制の試合を戦う。
投球はコースを狙ってパワーメーターをリリースし、打撃はカーソルとタイミングで打ち分ける。

## 必要な環境

- Node.js 20 以上
- npm

## セットアップ

```bash
npm install
npx playwright install chromium
```

`npx playwright install --with-deps` が sudo を要求する場合は、`--with-deps` を付けずにブラウザ本体だけを取得してください。

## コマンド

| コマンド             | 内容                                         |
| -------------------- | -------------------------------------------- |
| `npm run dev`        | 開発サーバー（http://127.0.0.1:4173/）       |
| `npm test`           | ユニットテスト（Vitest）                     |
| `npm run test:watch` | ユニットテストを監視モードで                 |
| `npm run test:e2e`   | E2E テスト（Playwright）                     |
| `npm run test:all`   | ユニット + E2E                               |
| `npm run lint`       | ESLint                                       |
| `npm run format`     | Prettier で整形                              |
| `npm run verify`     | lint + フォーマットチェック + ユニット + E2E |

開発サーバーは **HTTP で開く必要があります**。`file://` ではブラウザが ES Modules を読み込めないため、`index.html` を直接開くことはできません。

## 遊び方

1. タイトル画面で「チームを作る」を押す。
2. チーム編成画面で両チームの打線を組む。
   - 上部のタブで **ホーム** と **アウェイ** を切り替えられる。対戦相手（アウェイ）も名前・選手・能力値・打順・守備位置を自由に編集できる。
   - 画面上部の「チーム名」から好きなチーム名に変更できる（Enter でも確定）。
   - 各選手の「編集」から、ミート・長打力・走力・選球・球速・制球・変化球・スタミナ・守備・肩・送球を 1〜100 で指定できる。スライダーでも数値入力でも編集できる。
   - 名前・背番号・打席・投げ腕、守備位置ごとの適性も編集できる。
   - ▲▼ で打席順、守備位置の入れ替えフォームで守備位置を変更する。
   - 控えは「＋ 控えを追加」で増やし、「×」で削除できる（最大 8 人）。「›」で 1 番の打席と入れ替えられる。
3. プレイモードを選んで「試合開始」。疑似3Dのフィールドで 9 回まで戦う。
   - **投球**: 球種（ストレート / スライダー / カーブ / チェンジアップ）を選び、3×3 のコースをクリック。動くパワーメーターが緑ゾーンに来たところで「リリース」を押す。タイミングが良いほど制球が安定する。
   - **打撃**: 打席カーソルを合わせ、タイミングバーが緑ゾーンに来たところで「ミートで打つ」「強振する」を選ぶ。カーソルとコースが一致すると捉えやすい。
   - **1人プレイ**: ホームを操作し、アウェイは CPU が操作する。
   - **2人プレイ**: 投手側がコースとメーターを操作し、打者側がカーソルとタイミングで打つ。表裏でプレイヤー1（ホーム）とプレイヤー2（アウェイ）が交互に操作する。
   - 四隅のコースはボール気味。ミートは当てる確率、強振は長打力が上がるが空振りも増える。
   - 内角・外角は打者視点で表示され、左打者（スイッチヒッターは投手と反対打席）では左右が入れ替わる。
   - 安打・アウトは「レフト前安打」「遊撃ゴロ」のように打球方向付きで表示される。
4. 9 回を終えると結果画面。回別スコア、試合概況、長打のまとめを確認できる。
   - 「もう一度対戦」で同じチームのまま再戦、「編成に戻る」で選手を編集し直せる。
   - 途中で「最後まで自動で進める」を押すと、両チーム AI で試合を終わらせられる。
   - 1 球ごとに試合の途中経過を自動保存する。再読み込みするとタイトル画面から「続きから」で再開できる。

### キーボード操作

- 投球: `1`〜`9` でコース選択、`Space` でメーター開始 / リリース
- 打撃: 矢印キーでカーソル移動、`Z` ミート、`X` 強振、`Space` 見送り
- マウス・タッチでも同じ操作ができる

## チームデータの保存・読み込み

編成画面の「両チームのデータを文字列で保存・読み込み」を開くと、ホームとアウェイをまとめた 1 本の JSON 文字列を出力できる。

- 「コピー」でクリップボードへ、「ファイル保存」で `.json` ファイルとして保存。
- 保存した文字列を貼り付けて「読み込む」を押すと、両チームのチーム名・選手・能力値・打順・守備位置・控えがそのまま復元される。
- ファイル選択からも読み込める。
- 文字列は `format` と `version` を持つ JSON。手で編集した場合も能力値は 1〜100 に丸められ、編成が不正なら日本語のエラーを表示する。
- 以前の 1 チームだけのデータ（`mikanbaseball-team`）も読み込め、その場合は現在選択中のチームに適用される。
- 下のサンプルは選手配列の中身を省略しています。

```json
{
  "format": "mikanbaseball-match",
  "version": 1,
  "home": { "name": "みかんタイガース", "starters": [], "bench": [] },
  "away": { "name": "東風タイガース", "starters": [], "bench": [] }
}
```

## スマートフォン対応

画面幅 860px / 720px / 560px でレイアウトを切り替える。スマホでは編成・能力値エディタが 1 列になり、投球コースや打撃ボタンはタップしやすいサイズで表示される。

試合画面は**横画面推奨**。縦向きのときは「横画面でプレイしてください」というオーバーレイを表示する。横画面では疑似3Dフィールド、投球メーター、打撃カーソルをコンパクトに配置し、横スクロールなしで操作できる。

## ディレクトリ構成

```
index.html            エントリーポイント
src/
  main.js             起動、画面遷移、イベント配線（DOM を触るのはここ）
  game/
    constants.js      試合ルール上の定数
    abilities.js      能力値の定義・総合評価・星評価
    positions.js      守備位置と打球位置
    roster.js         選手・チーム・編成のモデルと検証、能力値の更新
    teamCode.js       チームデータの文字列化・復元
    camera.js         疑似3Dカメラと透視投影
    field.js          フィールド座標、守備位置、打球方向
    runners.js        走者の進塁（安打・四球）
    rng.js            再現可能な擬似乱数
    simulate.js       1 打席ずつ解く自動シミュレーション
    liveGame.js       1 球ずつ操作する対話型の試合エンジン
  data/rosterFactory.js 選手・チームのランダム生成
  ui/
    teamScreen.js     編成画面と能力値エディタ
    gameScreen.js     試合画面（スコアボード・投球／打席操作）
    matchView.js      疑似3DフィールドのCanvas描画
    resultScreen.js   結果画面
    rosterOps.js      打席順・守備位置・控えの入れ替え
  styles/main.css     スタイル
tests/
  unit/               Vitest（Node 上で動くロジックテスト）
  e2e/                Playwright（実ブラウザでの操作テスト）
scripts/serve.js      依存ゼロの静的ファイルサーバ
```

## 設計方針

- **ビルドしない**。実行時依存はゼロで、ブラウザがそのまま ES Modules を実行する。
- **ゲームロジックは DOM に依存しない**。`src/game/` は Node 上で動くので高速にテストできる。
- **乱数は必ずシード付き**。同じシードなら同じ試合結果になるため、テストが安定する。
- **E2E は `data-testid` で要素を探す**。class 名や文言に依存しない。
- **状態は 1 つの情報源**。試合エンジンが state をその場で更新し、UI は state を読んで全再描画する。

## 実装済みのゲームルール

- 9 回まで。延長戦はなし（同点なら引き分け）。
- 3 アウトで攻守交代。9 回表終了時にホームがリードしていれば裏は行わない。
- 9 回裏にホームが勝ち越したらサヨナラで終了。
- 四球は押し出しのときだけ走者が進む。
- 安打は 1 塁 / 2 塁 / 3 塁 / ホームランの 4 区分。走者は塁数ぶん進む。
- 1 打席はボール・ストライク・ファウルのカウント管理で決着する。
- 守備力・守備位置適性・投手能力が打球結果とエラー率に影響する。
- 能力値エディタで 11 項目の能力、プロフィール、守備適性を編集できる（スライダー／数値入力）。
- 控え選手の追加・削除（最大 8 人）と、打席順・守備位置の入れ替え。
- 左右打者で内角・外角の表示が入れ替わる。
- 安打・アウトは打球方向付きで表示される。
- 疑似3Dフィールド、投球パワーメーター、打撃カーソル＋タイミング操作。
- 試合の途中経過を localStorage に自動保存し、再開できる。
- チーム名の変更と、編成データの文字列・ファイルでの保存／復元。
- ホーム・アウェイ両チームの編集。
- 1人プレイ（対戦相手は CPU）と 2人プレイ（両チームを交互に操作）。
- 投手交代、代打・代走、延長戦は未実装。
